# decodelabs_internship_week1
This project is a rule-based AI chatbot named RuleBot, designed to simulate simple conversation using pattern matching and keyword detection rather than machine learning. The chatbot follows a clean Input-Process-Output (IPO) architecture, making its logic easy to trace and extend. In the Input phase, user messages are sanitized and normalized — converted to lowercase and stripped of extra whitespace — to ensure consistent matching regardless of how the input is phrased. The Process phase is the core of the bot's intelligence: it maintains a structured knowledge base where each intent, such as greetings, wellbeing checks, identity questions, or expressions of gratitude, is mapped to multiple possible trigger keywords and multiple possible responses. Keyword matching is done using regular expressions with word boundaries, which prevents false positives like matching "yo" inside the word "you." A standout feature is the bot's simple memory system: it can detect when a user introduces themselves using a phrase like "my name is X," extract and store that name, and personalize future responses by occasionally including it in replies. This gives the chatbot a lightweight sense of continuity and personality across a conversation, despite having no underlying AI model. Response variety is achieved through randomization, so the same input doesn't always produce an identical reply, making interactions feel less robotic. The Output phase handles displaying responses back to the user in a continuous loop that runs until an exit command like "bye" or "quit" is detected, at which point the bot delivers a personalized farewell if it knows the user's name. If no keyword matches the input, the bot gracefully falls back to a default response guiding the user toward supported commands. Overall, this project demonstrates foundational concepts in rule-based natural language interaction, including intent recognition, state management, and conversational design patterns, serving as a stepping stone before introducing more advanced AI-driven chatbot techniques.
